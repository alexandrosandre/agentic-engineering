# siesta

**What.** An alias of [`afk`](../afk/README.md). It invokes `afk` and follows it end to end.

**Why.** Aliases are cheap and people type what they think of. The alias holds nothing of its own, so the behavior has one home, and it is user-invoked only (`disable-model-invocation`) so it never competes with `afk` for the model's attention.
