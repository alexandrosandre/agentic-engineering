# spanish-copy

**What.** A short register guide for any Spanish the agent writes, in Spain Spanish.

**Why.** Frontier models know the RAE and Fundéu norms; their failure is falling back to English habits and generated-text cadence: spaced dashes as pauses, English quotes and decimal points, "no es X, es Y" chains, triads, filler openers, calques like «en base a», and dev jargon translated into words no Spanish-speaking developer says out loud («fusionar» for merge). The guide names those tics instead of restating grammar, which is what keeps it a dozen lines. Two lines are the team's own corrections rather than model tics, and are marked so a future re-vet keeps them.

**How it fits.** Loaded by `snippets` and whenever the agent writes Spanish a person will read. The same shape — a handful of the reading model's documented tics plus the team's own corrections — works for any language.

**Wire up.** Nothing.
